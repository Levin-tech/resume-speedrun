# 简历速通

一个免费开源的 Chrome / Edge 浏览器插件（Manifest V3），帮你在国内网申
页面一键填好简历信息——**插件绝不自动提交**，填完由你自己检查、自己
点提交。

## 功能规划

- ✅ 第 0 阶段：项目骨架、本地测试页、构建与测试流程
- ✅ 第 1 阶段：完整的简历信息库（基本信息/求职意向/教育/
  实习/项目/技能，自动保存到本机、支持导入导出 JSON）；Moka、北森、
  飞书招聘、牛客、智联、51job 自动生效，其他网站可在插件弹窗里点
  "在本页启用"按需注入
- ✅ 第 2 阶段：一键扫描网申页面，自动识别每个输入框对应简历里的哪一项
- ✅ 第 3 阶段（当前）：在插件弹窗点"开始填写"，模拟真实操作填写各类
  控件：文本框、普通下拉、可搜索下拉、日期选择器、拆分式年月下拉 +
  "至今"、城市级联、单选多选；简历经历比页面多时自动点"添加"补齐
- ✅ 填写完成后页面右上角给出检查清单（已填绿 / 需确认黄 / 未填红，
  必填没填的置顶，点条目跳到对应位置），支持"撤销本次填写"；你确认
  无误后自己点提交
- 🚧 适配真实网站（Moka、北森、飞书招聘……）的页面细节
- 🚧 你点提交后，插件自动记录这次投递（公司、岗位、网址、日期），
  可导出 Excel
- 🚧 可选：配置你自己的 DeepSeek 或任意 OpenAI 兼容接口 Key，让规则
  识别不了的字段交给 AI 判断——**只发送字段标签文本，绝不发送你的
  简历内容**；不配置 Key 也能正常使用规则功能

## 隐私说明

- 所有数据（简历库、投递记录、AI Key）只存储在你本机浏览器的
  `chrome.storage.local` 里，插件不依赖任何后端服务器，也不会把你的
  简历数据上传到任何地方。
- 唯一会离开你电脑的数据是：当你自己配置了 AI Key、且某个表单字段
  规则识别不了时，插件会把**该字段的标签文本**（例如"政治面貌"）
  发送给你自己配置的 AI 接口，用来判断这个框对应简历里的哪一项——
  不会发送简历的实际内容。
- 插件不会替你点击"提交/保存/下一步/确认/投递"等按钮，投递永远由你
  自己确认和操作。

## 安装方法（开发者模式）

目前处于早期开发阶段，还没有上架应用商店，需要手动加载。有两种方式
拿到 `dist/` 目录，任选一种：

### 方式一：不装 Node，直接下载构建好的插件（推荐给不写代码的用户）

1. 打开本仓库的 [Actions 页面](../../actions)，点进最新一次
   `main` 分支上成功（绿色 ✅）的 **CI** 运行记录。
2. 在页面底部 "Artifacts" 里下载 `resume-speedrun-dist.zip`，解压到
   任意目录（解压后的文件夹里应该能直接看到 `manifest.json`）。
3. 打开 Chrome（或 Edge），访问 `chrome://extensions`（Edge 为
   `edge://extensions`）。
4. 打开右上角"开发者模式"。
5. 点击"加载已解压的扩展程序"，选择第 2 步解压出来的文件夹。
6. 插件图标"简历速通"会出现在工具栏，点击可打开弹窗；右键图标 ->
   "选项"可以打开信息库编辑页。

以后每次插件更新，重复上面 1-2 步下载新的 zip、解压覆盖旧文件夹，
再回到 `chrome://extensions` 点一下插件卡片上的刷新按钮即可。

### 方式二：本地用 Node 构建

1. 安装依赖并构建：

   ```bash
   npm install
   npm run build
   ```

   构建产物会输出到 `dist/` 目录。

2. 打开 Chrome（或 Edge），访问 `chrome://extensions`（Edge 为
   `edge://extensions`）。
3. 打开右上角"开发者模式"。
4. 点击"加载已解压的扩展程序"，选择本项目的 `dist/` 目录。
5. 插件图标"简历速通"会出现在工具栏，点击可打开弹窗；右键图标 ->
   "选项"可以打开信息库编辑页。

修改代码后重新运行 `npm run build`，再去 `chrome://extensions` 页面
点一下插件卡片上的刷新按钮即可。

### 生效范围

- 以下网站打开后插件会自动生效：Moka（moka.com/mokahr.com/
  taleflow.cn）、北森（beisen.com/zhiye.com）、飞书招聘
  （feishu.cn/feishu-pre.net）、牛客（nowcoder.com）、智联
  （zhaopin.com）、51job（51job.com）。
- 其他网申页面（比如公司自建的招聘系统）不会自动注入，点击插件图标
  打开弹窗，点"在本页启用"即可在当前页临时启用一次（基于 Chrome 的
  `activeTab` 权限，插件不会预先申请访问所有网站的权限）。

## 本地开发 / 测试

```bash
npm install          # 安装依赖
npm run build        # 打包插件到 dist/
npm run build:fixtures  # 打包本地测试页（真实 Ant Design Vue 组件）到 test/fixtures/dist/
npm test             # 依次跑：构建插件 -> 构建测试页 -> 单元测试 -> 冒烟测试
```

- `test/fixtures/index.html` 是一个用真实 Ant Design Vue 组件搭的
  模拟网申表单，本地用浏览器直接打开（或通过
  `node scripts/static-server.mjs` 起个本地服务）就能试用插件效果。
- 单元测试：`npm run test:unit`（vitest）
- 端到端冒烟测试：`npm run test:e2e`（Playwright，加载打包好的插件
  并确认内容脚本注入成功）
