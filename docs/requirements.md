# 需求文档：简历速通

## 一句话介绍

一个免费开源的 Chrome/Edge 浏览器插件（Manifest V3，一套代码两边通用），
在国内网申页面（Moka、北森、飞书招聘优先，之后是牛客、智联、51job）
一键填好简历信息。插件绝不自动提交，由用户检查后自己点提交；用户点
提交时自动记录投递（公司、岗位、网址、日期），可导出 Excel。数据只存
本机浏览器，不要任何后端服务器。协议：GPL-3.0。

## 核心设计

### 整体流程

1. 扫描页面控件（scanner）
2. 规则识别（matcher）：平台适配器优先，其次通用关键词规则
3. 有把握就填；没把握且用户配置了 AI Key 时，交给 AI 判断"这个框对应
   简历哪一项"（只发字段标签，不发简历内容）
4. 本地填写（filler）
5. 填后检查清单（review）：已填 / 需确认 / 未填，必填项提醒
6. 用户自己检查并提交
7. 自动记录投递

### 填写引擎

要能"模拟人工点选"，覆盖以下控件形态：

- 组件库下拉：点开 -> 等浮层 -> 点选项 -> 校验 -> 关闭
- 可搜索下拉：输入关键词 -> 等候选列表 -> 点选目标候选项
- 日期选择器
- 拆分式"年/月—年/月"下拉 + "至今"勾选框
- 城市级联选择器
- 自定义单选/多选控件

每填一项都要回读校验是否生效；逐项串行执行，避免多个浮层同时打开、
互相遮挡。

### 多段经历

教育经历、实习经历、项目经历都可能有多段。填写引擎要能自动点击对应
区块内的"添加/新增"按钮再填下一段。

**永远不点击**"提交/保存/下一步/确认/投递/删除"类按钮——这是硬性
黑名单，任何自动点击前都要先检查按钮文案不在黑名单内。

### 简历数据结构

固定结构 JSON（定义见 `src/shared/schema/resume.js`）：

- 日期存 `{ year, month }`，不存字符串
- 可枚举字段存标准值（如学历存"硕士"、政治面貌存"共青团员"），
  配同义词表对应各网站的实际写法
- 教育经历 / 实习经历 / 项目经历为数组，支持多段
- 需要包含：院校类型（985/211/双一流/普通本科）、学历类型（全日制/
  非全日制）、所在行业、期望行业等字段

### AI 判断（可选功能）

- 用户自带 DeepSeek 或任意 OpenAI 兼容接口的 Key
- 不填 Key 也能用规则功能，AI 只是规则匹配不上时的兜底
- 只发送字段标签文本给 AI，绝不发送简历内容

## 分阶段计划

### 第 0 阶段（本次任务）：搭架子

- 项目结构：MV3 骨架，按模块分目录（background / content 的 scanner-
  matcher-filler-adapters-review / popup / options / shared）
- 各模块先写好接口和注释，内容先占位
- esbuild 打包，`npm run build` 生成 `dist/`，可在
  `chrome://extensions` 用"加载已解压的扩展程序"直接加载
- 本地测试页（`test/fixtures/`）：用真实前端组件库（Ant Design Vue）
  搭建模拟网申表单
- 测试：vitest 单元测试 + Playwright 冒烟测试，`npm test` 一次跑完
- README（中文）+ GPL-3.0 协议说明

### 后续阶段（未开始）

- 逐个平台实现真实的 scanner / matcher / filler 逻辑，从 Moka 开始
- 实现 review 检查清单的具体 UI
- 实现 popup（简历库切换、开始填写）和 options（简历库编辑表单、AI
  Key 设置、投递记录导出 Excel）的具体交互
- 接入 AI 兜底判断的真实调用
- 扩展支持牛客、智联、51job

## 测试页要求（test/fixtures/）

用真实的前端组件库（优先 Element Plus 或 Ant Design，通过 npm 安装并
打包成本地静态页，不能手写假组件）模仿网申表单，至少包含：

- 组件库下拉（政治面貌、民族）
- 可搜索下拉（国家、学校、专业，需点选候选项才算选中）
- 日期选择器
- 拆分式"年/月—年/月"下拉 + "至今"勾选框
- 城市级联
- 单选多选
- 文本框
- "教育背景/实习经历"区块和"+ 添加"按钮
- 一个"提交"按钮

以后每个功能都先在这里测。当前实现基于 Ant Design Vue 4。
